# TOEFL 2026 Reading Practice Simulator

Live Demo: https://palaso-dev.github.io/toefl-test-simulator/

Interactive web simulator for the **TOEFL 2026 Reading** format featuring 17 complete practice tests (Module 1 & Module 2, including HARD 2nd Module tests 6–17) with official Answer Keys.

## Features

- **17 Complete Practice Tests** (2 modules per test)
- **Complete the Words (Questions 1–10):** Inline single-letter input boxes with auto-advance and overwrite support
- **Read in Daily Life & Academic Passa∫es:** Split-pane reading layout with bolded quoted references and interactive multiple-choice options
- **Instant Answer Checking:** Check individual questions (`Check Answer`) or view the full Answer Key (`View All Answers`) at any time and resume your exam
- **Timed & Untimed Modes:** Optional 18-minute per-module timer and local best-score tracking

## Local Usage

Open `index.html` directly in your browser.
